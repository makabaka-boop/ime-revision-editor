# Track-Changes Editor

只含**段落、普通文字、加粗**三种内容的浏览器编辑器，支持可**接受或拒绝**的插入、删除修订。

- 文档模型与 DOM 选区互相映射：跨段选择、粘贴纯文本、拆分/合并段落后，光标仍指向正确的字符
- 输入法（IME）组合期间显示临时内容，但**组合结束才提交一笔可撤销事务**
- 浏览器连续触发的 `beforeinput` / `input` / 组合事件不会把同一次输入记两遍
- 接受、拒绝修订与撤销/重做都保持光标位置和段落结构有效
- 粘贴的 HTML 只取纯文本，**绝不作为可执行标记进入文档**
- 阅读视图、修订表、导出从**同一个模型**生成

## 运行

```bash
npm test          # Node 测试（36 个用例，无第三方依赖）
```

浏览器冒烟：用任意静态服务器打开 `demo/index.html`，例如：

```bash
npx serve .       # 然后访问 /demo/
```

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/model.js` | 纯数据文档模型（字符/段落/修订），不依赖 DOM。插入、删除、跨段合并、拆段、接受/拒绝均在此完成，可脱离浏览器测试 |
| `src/editor.js` | 事务与快照式撤销栈、输入法组合状态机、`beforeinput` 事件去重、修订接受/拒绝 |
| `src/dom-host.js` | contenteditable 渲染与「模型选区 ↔ DOM Range」双向映射、浏览器事件接线 |
| `src/render.js` | 阅读视图（tracked/final/original）、修订表、Markdown/HTML/JSON/纯文本导出 |
| `test/` | Node 测试与 `FakeHost`（模拟与真实宿主相同的逻辑↔DOM 镜像换算） |

## 文档模型

- `DocumentModel.paragraphs: Paragraph[]`，`Paragraph.chars: Char[]`
- `Char = { id, ch, bold, ins, del }`
  - `id`：稳定标识，DOM 节点以 `data-cid` 与字符一一对应；跨段操作与撤销后仍能定位同一字符
  - `ins`：插入修订 id（`null` 表示基线字符）
  - `del`：删除修订 id（被删字符仍物理保留，用于拒绝恢复和修订显示）
- 逻辑偏移只数**存活字符**（无 `del`）；被删字符在物理数组中聚簇存放，
  `physicalIndex` 会跨过删除聚簇，因此「逻辑光标位置 ↔ 物理/DOM 子节点位置」始终一一对应

### 跨段删除

- 物理排布：锚段存活前缀 ｜ 被删字符聚簇（按原物理顺序）｜ 末段存活后缀
- 被并走段落的完整字符顺序快照保存在删除修订的 `moved` 中；
  **拒绝**时按快照确定性重建段落骨架，再把字符放回原物理位置
- 删除未接受的**插入字符**时直接物理移除（并从其插入修订中裁剪），不与删除修订重叠标记

## 输入法事件去重

1. 非组合期只在 `beforeinput` 改模型，并 `preventDefault()`，浏览器不会再改 DOM；
   `input` 事件只用于对账，**从不修改模型**。
2. 组合期间不拦截，DOM 由浏览器原生更新；模型写一份临时字符（`ins = '__composition__'`），
   不产生修订、不入撤销栈、不重建 DOM（重建会打断 IME）。
3. `compositionend` 时移除临时字符、写入正式插入修订。整次组合（含开始时的选区删除）
   共享组合前快照，因此无论组合更新触发多少次，都只有**一笔**撤销事务。
4. Chrome 系在 `compositionend` 后会补发一对 `insertText` 的 `beforeinput/input`，
   按「位置 + 内容」吻合度吞掉一次（一次性标记），避免同一次输入记两遍；
   用户后续自行输入的相同内容位置不匹配，不会被误吞。

## 粘贴

`paste` 事件始终 `preventDefault()`：优先使用 `text/plain`，否则把 HTML 经
`DOMParser` 取 `textContent`（脚本、事件属性、标签全部丢弃），多行按段落拆分，
整次粘贴是一笔插入修订 / 一笔事务。

## 测试覆盖（节选）

- 中文组合：多段临时更新 → 一笔事务；Chrome 补发事件去重；Firefox 无补发；
  空组合（Esc）不入栈；组合替换选区时删除 + 插入为一笔
- 跨段 Backspace / 选区删除：段落合并、光标落位、镜像下标往返、拒绝后段落重建
- 拆并段落后紧邻删除修订字符的位置映射
- 粘贴纯文本多行、恶意 HTML 去标记、粘贴覆盖选区
- 接受 / 拒绝 / 撤销 / 重做顺序与光标有效性
- tracked/final/original 三视图、修订表跨段标记、导出与模型一致且转义安全
